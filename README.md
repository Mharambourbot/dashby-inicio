# DashBy · inicio

Página que solo pone el ícono de DashBy para la pantalla de inicio del celular y abre la app de Streamlit adentro.
No contiene datos, claves ni código de la app (ese está en el repositorio privado App-DashBy).

También tiene un "despertador" (`despertador.py` y `.github/workflows/despertador.yml`): una tarea de GitHub que abre la app varias veces al día para que Streamlit no la duerma. Solo visita la app; no escribe contraseñas ni guarda nada de lo que muestra.
